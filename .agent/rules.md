# Стандарты кодирования

- **DRY** – не дублируй логику.
- **KISS** – предпочитай простые решения.
- **Тесты** – обязательны для новой функциональности.
- **Code style** – стандартный rustfmt (макс. длина строки 100).
- **Обработка ошибок** – использовать `anyhow` для бинарников, `thiserror` для библиотек.
- **Cross-platform** – использовать `std::path::Path` для путей, избегать Windows-специфичных команд.

# Операции в ОС
- Всегда перед началом операций в ОС, первоначально проверяй, что эта за ОС, на которой ведется разработка, чтобы понять какие команды (Windows, Linux) давать на выполнение.
