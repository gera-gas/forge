# Технологический стек

- **Язык**: Rust 1.78+
- **CLI Framework**: Clap (derive macros)
- **Config**: TOML (forge.toml)
- **LLM Interface**: OpenAI API compatible endpoints
- **HTTP Client**: reqwest
- **File system operations**: std::fs, walkdir
- **TOML parsing**: toml
- **Markdown parsing**: pulldown-cmark
