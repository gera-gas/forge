## Описание
Генерировать файлы сборки (CMake, Bazel и др.) через LLM на основе TOML-спецификации.

## Требования
1. Команда: `forge template new --lang c --build cmake`.
2. Чтение `project.forge.toml` в корне проекта.
3. Генерация файлов сборки через LLM.
4. Поддержка языков: C, C++, Rust.
5. Поддержка систем сборки: CMake, Bazel, Make.

## Технические детали
- Использовать `toml` для парсинга `project.forge.toml`.
- Шаблоны промптов в `llm/prompts.rs`.
- Генерация в `cli/template.rs`.

## Критерии приемки
- [ ] `forge template new --lang c --build cmake` создает CMakeLists.txt.
- [ ] LLM генерирует корректный CMake-файл.
- [ ] Поддержка разных языков и систем сборки.
- [ ] Работает на всех платформах.
