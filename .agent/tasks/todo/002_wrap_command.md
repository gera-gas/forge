## Описание
Анализировать существующий код проекта и генерировать описание в `.agent/` с использованием LLM.

## Требования
1. Команда: `forge wrap [--source ./src] [--model gpt-4o]`.
2. Чтение файловой структуры (tree).
3. Выборка ключевых файлов (основываясь на эвристиках: `main.rs`, `lib.rs`, `Cargo.toml`, `README.md`).
4. Формирование промпта для LLM: "Проанализируй этот код и сгенерируй `concept.md`, `struct.md` и `tech_stack.md` в формате...".
5. Запись полученных файлов в `.agent/`.
6. Использовать API Key из ENV: `FORGE_API_KEY` / `OPENAI_API_KEY`.
7. Поддержка cross-platform.

## Технические детали
- Использовать `reqwest` для HTTP-запросов.
- Логика сканирования в модуле `scanner`.
- Шаблоны промптов в `llm/prompts.rs`.

## Критерии приемки
- [ ] Утилита корректно отправляет контекст в LLM.
- [ ] LLM возвращает валидный Markdown.
- [ ] Файлы создаются в нужных местах.
- [ ] Работает на Windows, Linux, macOS.
