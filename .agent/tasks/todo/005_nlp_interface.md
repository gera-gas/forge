## Описание
Интерпретация естественного языка через LLM и выполнение полученных команд.

## Требования
1. Команда: `forge ask "создай задачу на рефакторинг модуля auth"`.
2. Преобразование естественного языка в команды через LLM.
3. Выполнение полученной команды (например, создание задачи).
4. Поддержка команд: `create_task`, `list_tasks`, `start_task`, `done_task`.

## Технические детали
- Использовать небольшую модель (Llama 3 8B) для быстрых ответов.
- Шаблоны промптов в `llm/prompts.rs`.
- Логика выполнения команд в `cli/ask.rs`.

## Критерии приемки
- [ ] `forge ask "создай задачу тестирование"` создает задачу.
- [ ] Команда корректно преобразует NLP в действие.
- [ ] Поддержка основных команд.
- [ ] Работает на всех платформах.
