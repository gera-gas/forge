# Concept

CLI утилита `forge` — менеджер спецификаций проекта. Создаёт и поддерживает структуру `forge-src/` — структурированные описания на человеческом языке, которые служат **спецификацией** для ИИ-агентов: контекстом для работы и основой для генерации кода.

Ключевая парадигма: **`forge-src/` файлы — это спецификация, а не исходный код.** Код на языке программирования — одна из возможных реализаций этой спецификации. ИИ-агент выступает «транслятором» спецификации в реализацию.

## Роли в экосистеме

| Компонент | Роль | Фаза |
|-----------|------|------|
| **forge CLI** | Менеджер спецификаций — создаёт и поддерживает `forge-src/` | MVP (сейчас) |
| **VSCode Extension** | GUI-редактор спецификаций — Kanban-доска, формы | Phase 1 |
| **ИИ-агент** | Транслятор спецификации → код (недетерминированный) | Phase 2 |
| **Cloud/Sync** | Синхронизация для команд | Phase 3+ (отложено) |

## Цели

1. Стандартизировать взаимодействие между человеком и ИИ через файловую систему.
2. Ускорить онбординг ИИ в новый проект (с 0 до понимания контекста за 1 команду).
3. Автоматизировать рутину: создание шаблонов, генерация описаний кода.
4. Быть мостом между спецификацией (`forge-src/`) и реализацией (код на ЯП):
   - `forge wrap` — код → спецификация («декомпилятор»)
   - `forge generate` — спецификация → код («транслятор»)

## Ограничения

- Работает только на Rust-проектах (для начала)
- Требует интернет для LLM-функций (`wrap`, `generate`, `ask`)
- API-ключ для LLM (OpenAI/Anthropic)
- ИИ-агент недетерминирован — результат генерации требует проверки (компиляция, тесты, ревью)
