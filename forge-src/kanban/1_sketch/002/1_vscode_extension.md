# VSCode Extension (MVP)

**Приоритет:** MVP (первый релиз)  
**Родитель:** [0_base_idea.md](0_base_idea.md)

---

## Цель

Графическая Kanban-доска для работы с `forge/kanban/` внутри VSCode.

---

## Основные возможности

### MVP (Phase 1)

1. **Графическая Kanban-доска**
   - Отображение всех стадий: backlog, sketch, design, todo, in_progress, done
   - Drag & drop для перемещения задач между стадиями
   - Цветовая кодировка по типу задачи (feature, fix, spike, chore)
   - Приоритеты с визуальными индикаторами

2. **Работа с задачами**
   - Создание новых задач (всплывающее окно с формой)
   - Редактирование задач через webview panel
   - Просмотр деталей задачи

3. **Git-интеграция (базовая)**
   - Отображение текущей ветки и связанной задачи
   - Автоматическое создание веток при перемещении задачи в todo

4. **Публикация в VSCode Marketplace**

### Phase 2

5. **Расширенная Git-интеграция**
   - Быстрые команды: Start Work, Done, Create PR
   - Показ коммитов, связанных с задачей

6. **История изменений задачи** (git log)

7. **Фильтрация и поиск задач**

8. **Настраиваемые колонки и теги**

---

## Техническая реализация

- **Язык:** TypeScript (стандарт для VSCode extensions)
- **Framework:** VSCode Extension API + React для webview
- **State management:** VSCode Memento (для сохранения настроек) + чтение `forge/kanban/` файлов
- **Git integration:** Simple Git или прямые вызовы git CLI
