## Цель

Монетизация через платные функции для команд и enterprise-клиентов.

---

## Модель монетизации

| Тир | Цена | Возможности |
|-----|------|-------------|
| **Free** | $0 | CLI + VSCode Extension + локальная kanban + свои API-ключи |
| **Pro/Team** | $X/мес | Синхронизация с Jira/Trello, командная работа, аналитика |
| **Enterprise** | По запросу | On-premise, SSO, кастомные модели, SLA |

Принцип: соло-разработчик никогда не платит, команда — платит за синхронизацию и управление.

---

## Jira/Trello синхронизация (Pro)

**Возможности:**
- Двусторонняя синхронизация с Jira, Trello, Linear, GitHub Projects
- При `forge task move 001 in_progress` → задача автоматически обновляется в Jira
- При обновлении в Jira → файл в `kanban/` обновляется (через webhook или polling)
- Команда и менеджер видят изменения в реальном времени

**Техническая реализация:**
- API интеграции с Jira/Trello/Linear
- Webhook сервер для приёма изменений
- Конфигурация в `forge.toml`:
  ```toml
  [sync]
  provider = "jira"
  url = "https://company.atlassian.net"
  project = "FORGE"
  api_key_env = "JIRA_API_KEY"
  ```
