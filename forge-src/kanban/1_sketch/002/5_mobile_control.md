# Мобильное управление

**Приоритет:** Phase 2  
**Родитель:** [0_base_idea.md](0_base_idea.md)

---

## Цель

Управление AI-агентами и задачами с мобильного телефона.

---

## Сценарий использования

Разработчик на совещании/в дороге:
1. Получает уведомление: "Dev завершил задачу 005, ждёт ревью"
2. Может с телефона одобрить или дать комментарии
3. Видит статус kanban-доски в реальном времени

---

## Этапы реализации

### Этап 1: Telegram Bot (Phase 2)

Самый простой путь — минимум разработки, максимум охвата.

**Команды:**
- `/status` — текущее состояние kanban-доски
- `/show 005` — детали задачи
- `/approve 005` — подтвердить перенос в done
- `/move 005 done` — переместить задачу
- `/comment 005 Текст` — добавить комментарий

**Уведомления:**
- Задача перемещена в in_progress
- Задача завершена (ждёт подтверждения)
- Ошибка при выполнении

**Технологии:**
- Telegram Bot API
- Backend: Rust (интеграция с forge CLI) или Node.js

### Этап 2: Мобильное приложение (Phase 3+)

Полноценное приложение с kanban-доской и управлением агентами.

**Технологии:**
- Tauri (разделяем Rust-код с CLI)
- Или React Native для быстрой разработки
