## Цель

Реализовать команду `forge ask`, которая принимает запросы на естественном языке и преобразует их в команды.

## Требования

### Функциональные

1. **Команда:** `forge ask "<запрос>"`
   - Пример: `forge ask "создай задачу на рефакторинг модуля auth"`
   - Пример: `forge ask "покажи список задач"`
   - Пример: `forge ask "начни задачу 001"`

2. **Поддерживаемые команды:**
   - `create_task` → `forge task add`
   - `list_tasks` → `forge task list`
   - `start_task` → `forge task start`
   - `done_task` → `forge task done`

3. **Преобразование через LLM:**
   - Отправка запроса к LLM с промптом
   - LLM возвращает JSON: `{"command": "task", "action": "add", "args": {"description": "..."}}`
   - Выполнение преобразованной команды

4. **Интерактивность:**
   - Перед выполнением показать команду и спросить подтверждение
   - `[y]es / [n]o / [e]dit`

### Технические

- **HTTP-клиент:** `reqwest` для LLM API
- **Промпт:** Специальный промпт для интерпретации команд
- **Парсинг JSON:** `serde_json`
- **Возможность использовать локальную модель:** Llama 3 8B через Ollama

## Промпт для LLM

```
You are a command interpreter for the "forge" CLI tool.
Convert natural language queries to structured commands.

Available commands:
- task add <description>
- task list
- task start <id>
- task done <id>

User query: "{query}"

Respond with JSON:
{
  "command": "task",
  "action": "add" | "list" | "start" | "done",
  "args": {...}
}
```

## Архитектурные решения

1. **Модульная структура:**
   - `src/cli/ask.rs` — логика команды
   - `src/llm/interpreter.rs` — интерпретация через LLM
   - `src/llm/prompts.rs` — промпты

2. **Выполнение команды:**
   - Парсинг JSON от LLM
   - Вызов соответствующей функции из других модулей
   - Обработка ошибок
