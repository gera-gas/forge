2. `tech_stack.md` — на чём строим (язык, библиотеки)

4. `rules.md` — стандарты кодирования
5. `codegen.md` — этот файл (правила генерации)
6. Текущая задача из `kanban/` — что делать сейчас

## Процесс генерации

1. Прочитать входные данные (`forge-src/` файлы + задача из kanban)
2. Спланировать изменения (какие файлы создать/изменить)
3. Сгенерировать код
4. Написать тесты
5. Проверить компиляцию (`cargo build` / `cmake --build`)
6. Запустить тесты (`cargo test` / `ctest`)
7. Запустить линтер (`cargo clippy` / `clang-tidy`)
8. Сообщить результат (что создано, что изменено, статус проверки)

## Ограничения

- Не использовать библиотеки не из `tech_stack.md`
- Не нарушать структуру из `struct.md`
- Не генерировать код вне описанной области
- Каждая новая функциональность = тест
- Не удалять существующие тесты без замены
